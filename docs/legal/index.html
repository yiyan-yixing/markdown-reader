Markdown Reader & Markdown Reader Pro — Policies

Effective: 2026-08-05 · Product by 一言一行 (yiyan-yixing)

Markdown Reader is a browser extension that renders Markdown files in a clean, three-panel reader. Markdown Reader Pro adds licensed themes as a one-time purchase. This page summarizes our data practices; full texts are linked below.

1. Privacy Policy

We don't run a server for your data. The extension has no backend of its own.

  • AI feature (BYO model): your API key is stored only in chrome.storage.local on your machine — it is never synced to Google, never sent to any server we control, and requests go directly from your browser to the model endpoint you configured.
  • Pro license: your license key is stored only in chrome.storage.local and is sent exclusively to LemonSqueezy (our Merchant of Record) for activation/validation. It is never transmitted to any server we control.
  • Settings & preferences: stored via Chrome's storage.sync/storage.local.
  • No analytics, no tracking, no advertising — we collect nothing.
  • declarativeNetRequest is used solely to remove the Origin header from this extension's own requests to localhost/127.0.0.1/0.0.0.0, so local AI servers (Ollama, LM Studio, …) accept the request. It never reads cookies, auth tokens, or response bodies, and never touches public domains.
