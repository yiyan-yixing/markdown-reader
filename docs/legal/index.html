PageSew — Privacy & Policies

Version 1.3.0 (draft) · Last updated: 2026-10-20; Effective date: date of first public release · Published by 一言一行 (yiyan-yixing)

PageSew is a free browser extension that renders Markdown files in a clean three-panel reader: local .md files and Markdown pages on GitHub, GitLab and Bitbucket. It has no account system, no analytics and no paid tier. This page summarizes our data practices; full texts are linked below.

1. Privacy Policy

The extension has no backend of its own and we run no server for your data.

  • Page text is rendered locally in your browser. It is never uploaded to us and never stored by the extension.
  • AI feature (bring your own model): selected text is sent only when you actively trigger translation or summarization, directly from your browser to the AI endpoint you configured. We do not relay, intercept or store it.
  • API key: stored in plain text in chrome.storage.local (key mdReaderApiKey). It is never synced, never exposed to the in-page script, and is read only by the background service worker. It goes only to your configured AI endpoint, as Authorization: Bearer or x-api-key.
  • Settings: stored in chrome.storage.sync (key mdReaderSettings) — theme, font size, content width, centering, outline, file tree, auto-refresh, custom CSS, plugin toggles, AI service / base URL / model, and language preferences. If you enable Chrome sync they sync to your own Google account under Google's terms; the API key is never included.
  • Remote requests go only to raw.githubusercontent.com, gitlab.com, bitbucket.org (raw Markdown) and api.github.com (directory listing). Whether your browser attaches an existing site session is decided by the browser; the extension does not read it.
  • AI output is shown in the current page only and is never written to extension storage.
  • No analytics, no telemetry, no advertising, no tracking, no accounts, no paid features.
  • declarativeNetRequest is used only for a single session rule (id 1001, action modifyHeaders) that removes the Origin request header from this extension's own requests to localhost, 127.0.0.1 and 0.0.0.0, so local model servers (Ollama, LM Studio, …) accept the request. It does not modify response headers, does not read request or response bodies, never touches public domains, and never reads cookies or credentials.

2. Free Software — No Purchases, No Refunds

PageSew is free. There is no paid version, no subscription, no purchase flow and no refund flow. Every published feature is available to all users. If a paid feature is ever introduced, full terms will be published separately and announced in advance, and will not apply retroactively.
